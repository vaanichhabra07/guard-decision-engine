# Guard Decision Engine

A C++ decision system that selects the safest door in a secured facility based on environmental signals.

## Approach

Instead of simple condition checks, the system:
- Evaluates signals (alarm, threat, override, power)
- Applies priority-based rules
- Ensures safe decision-making
- Explains each decision

## Analogy

The system behaves like a control desk operator:
observing signals and choosing the safest action rather than guessing outcomes.
